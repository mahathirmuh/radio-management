# Bahasa (Indonesia / English)

Rencana dan aturan fitur ganti bahasa. Dikerjakan di branch `i18n` per tahap, lalu dirilis sekaligus (1.13.0) setelah
semua halaman selesai, seperti design refresh.

## Keputusan (disetujui pemilik, 2026-10-21)

- Bahasa bawaan: **Bahasa Indonesia**, untuk akun yang belum memilih dan untuk halaman login.
- Pilihan disimpan **per akun** (kolom `users.locale`, migrasi `2026_10_21_100000_add_locale_to_users`) dan di
  browser (cookie `locale`, tidak dienkripsi). Sebelum migrasi dijalankan, cookie saja yang menyimpan; tidak ada yang gagal.
- Tombol: "ID | EN" di topbar, di sebelah lonceng notifikasi (sejak 1.13.1; di 1.13.0 ada di menu akun), di sidebar
  versi HP, dan "ID | EN" di kaki halaman login.
- Istilah yang tidak diterjemahkan: Dashboard, Register Radio, Stock Opname, COF Scan, ICT Masterlist, E-Sign Master,
  Import Excel, Audit Log, API Tokens, User Management, Super Admin, Role. Di Riwayat versi juga jenis rilis dan jenis
  perubahan (Minor release, Patch release, Major release, Added, Changed, Fixed, Removed, Security, Deprecated; sejak
  1.21.2).

## Cara kerja

- `App\Services\Language`: daftar bahasa (`NAMES`), bahasa sebuah request (akun → cookie → Indonesia), bahasa API.
- `App\Http\Middleware\SetLocale` berjalan dua kali untuk halaman: di middleware global (hanya cookie, untuk 404 dan
  halaman maintenance) dan setelah session (pilihan akun menang, lalu cookie disamakan). Untuk `/api/v1`: `SetLocale:api`.
- `App\Http\Controllers\LanguageController` (`POST /language`, `language.switch`): menyimpan ke akun bila kolomnya ada,
  memasang cookie, lalu kembali ke halaman asal (alamat lain ke `/`).
- Teks: `lang/<kode>/*.php` untuk bagian umum (`ui`, `menu`, `login`, `errors`, `access`, `notifications`, dan pesan
  bawaan Laravel di `lang/id`), `modules/<Module>/Resources/lang/<kode>/*.php` untuk tiap modul (namespace = nama
  modul, sama seperti view: `__('RadioManagement::checks.sn_empty')`).
- Nama menu sidebar: `Menu::label()` dari `lang/<kode>/menu.php`, per route (grup per judulnya, seksi per nilainya).
  Entri baru tanpa nama di sana tampil dengan judulnya di tabel.

## Aturan menulis teks

- Blade: `{{ __('...') }}`. Teks untuk script halaman lewat `@json(__('...'))`. **`@json` tidak boleh berisi koma**
  (Blade memotong argumennya di koma): hitung dulu di `@php`, lalu `@json($variabel)`.
- Placeholder memakai gaya Laravel, `:nama`. Di JavaScript diisi dengan `rmFill(teks, { nama })` (blok debounce di
  `main/components/js`) atau `RadioUi.fill` di halaman radio.
- Jumlah (satu/banyak) dengan `trans_choice`; Bahasa Indonesia cukup satu bentuk, English `{1} ...|[2,*] ...`.
- Angka dan tanggal mengikuti bahasa: `Language::number()`, `rmMotion.number()`, Carbon `translatedFormat()`,
  `rmPickers` (nama bulan dari `ui.pickers`).
- **Data tetap Bahasa Indonesia** (format yang dipakai pihak lain dan yang tersimpan): riwayat radio, entri Audit Log,
  file Excel import/export, label di REST API (`placement.label`, `condition.label`, `issues`). Kode yang menulis data
  memakai label Indonesia seperti sebelumnya (mis. `Placement::label()`); hanya tampilan yang meminta bahasa halaman.
- Pesan REST API: English, Indonesia untuk klien yang mengirim `Accept-Language: id`.
- Catatan rilis (Riwayat versi): `CHANGELOG.md` dalam Bahasa Indonesia, `CHANGELOG.en.md` dalam English. Setiap rilis
  ditulis di keduanya (sejak 1.21.0); `ChangelogDialogTest` menolak versi yang hanya ada di satu file.
- Test: `TranslationFilesTest` memastikan kedua bahasa punya file, kunci dan placeholder yang sama; `LanguageTest`
  menguji tombol dan penyimpanannya. Test halaman yang diperiksa dalam English memakai `Tests\Concerns\UsesEnglish`.

- [x] 5. Pemeriksaan akhir: teks setiap halaman dibandingkan kata per kata dengan 1.12.3 (halaman Indonesia tetap
  sama, halaman yang dulu English tetap sama dalam English), sisa kata Indonesia di versi English dicari (yang tersisa
  hanya data), tampilan English dilihat di browser; README, CHANGELOG, rilis 1.13.0.

Catatan dari pengerjaan:

- Teks yang dulu ditulis di kode (`NOT_READY`, `MESSAGES`) kini di file bahasa; yang tersimpan (riwayat, alasan
  arsip, Audit Log, ringkasan Stock Opname) tetap ditulis dalam Bahasa Indonesia, juga bila halamannya English
  (`withLocale('id')` di `RadioOpnames::submit`).
- `Radio::display_name` adalah data (API, Audit Log); halaman memakai `Radio::pageName()`.
- `TranslationFilesTest` juga menolak kunci yang ditulis dua kali dalam satu file (PHP diam-diam memakai yang terakhir).
- Bentuk jamak di JavaScript (`rmChoice`, `RadioUi.choice`) memilih seperti Laravel: rentang yang cocok, kalau tidak
  ada bentuk menurut aturan bahasanya.
